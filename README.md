# City Medical Store Website

Static, responsive website for City Medical Store, Dehradun.

## Included
- Responsive single-page website
- Home, About, Services, Home Delivery, Diagnostics, Location, Pharmacist, FAQ and Contact sections
- WhatsApp/call buttons
- Location QR image supplied by the user
- Location link
- Placeholder for email and DL number
- No e-commerce, cart or payment system

## Edit later
Open `index.html` and replace:
- `[ADD DL NUMBER]`
- `[ADD EMAIL]`

To change colors/text, edit `style.css` / `index.html`.
